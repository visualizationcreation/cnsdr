## Hosting


Static HTML and CSS, with no build or dependencies. GitHub Pages serves the root of `main`. Keep all website files at repository root. Episode links are edited in `index.html`.

Custom domain: `creativensdr.com`, registered and managed at Hostinger. Keep the repository's `CNAME` file when publishing updates. DNS uses GitHub Pages' four IPv4 addresses for `@` and `www` points to `visualizationcreation.github.io`. The website uses GitHub Pages hosting, not Hostinger AI Builder.
